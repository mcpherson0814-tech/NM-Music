NATHAN MCPHERSON MUSIC WEBSITE — PROJECT CONTEXT
=================================================
Last updated: July 27, 2026
Built by: Kyle McPherson (kyle@fetch.ly) via Claude Code


OVERVIEW
--------
Single-page HTML promo site for Nathan McPherson, indie country/americana artist.
No framework, no backend — plain HTML + CSS. Intentionally simple for easy hosting
and low cost. Hosted on Vercel, source on GitHub.

GitHub:  https://github.com/Kadllama/nathan-mcpherson-music  (public repo, Kyle's personal account)
Vercel:  Deployed under Nathan's Vercel team (Hobby plan, free tier)
Domain:  nathanmcphersonmusic.com — not yet purchased (~$11/year through Vercel)

TECH NOTES
----------
- No build step — Vercel deploys the HTML file directly (preset: Other)
- Root directory: ./  (all files at repo root)
- To redeploy: just push a commit to the main branch on GitHub — Vercel
  auto-deploys on every push
- SSL: handled automatically by Vercel (free, auto-renews)
- To add domain when purchased: Vercel dashboard → Project → Settings → Domains
